# Python Guessing Games

These are two individual projects that I developed while self-studying Python and Cybersecurity via Sololearn and TryHackMe. Through these exercises, I master Python's core syntax, logic control, and input/output processing. 

Notably, I rewrote the original example code (Guess the random number game) in TryHackMe, implemented exception handling, and significantly improved the program's robustness and security, making it resistant to invalid input.


## Project descriptions
1. **Fixed Number Guess** : Players need to guess a preset number between 1 and 20. (Practice if-else, while-break logic, input sanitization, and range validation)

2. **Random Number Guess** : The computer will randomly generate a number. Players need to guess the random number between 1 and 20. (Practice random module, Add try...except to resist invalid input)


## How to Run
1. Make sure your computer has **Python 3.12** installed.
2. Download the `.py` files from this repository.
3. Open a terminal or command prompt (CMD) and navigate to the folder.
4. Run your preferred game using the following commands:

   4.1. To run the Fixed Number Game:
   ```bash
   python guess_the_number_game.py
   ```

   4.2. To run the Random Number Game:
   ```bash
   python guess_the_random_number_game.py
   ```
